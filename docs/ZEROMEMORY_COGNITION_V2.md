# ZeroMemory Cognition V2 invariants

1. Durable state and working memory are different things.
2. ZeroPipe filters dormant memory before any model sees context.
3. Assistant output is never automatically promoted to durable truth.
4. User and application-authoritative memories may supersede an active value.
5. Superseded values leave episodic history but do not remain active current state.
6. Episodes decay faster than durable decisions and constraints.
7. Repeated episodes may consolidate into a durable fact only after a deterministic occurrence threshold.
8. Consolidation never grants authority or mutates application state outside ZeroMemory.
9. Memory remains model-provider independent.
10. The public context and observe contracts remain stable while retrieval internals evolve.
